The official cross-platform mobile companion app for **Enn Rev Enn Sourir (ONG 15420)**, Mauritius's premier NGO medical crowdfunding ecosystem.

---

## 📱 Features

- **Real-Time Medical Appeals:** Live synchronization with Supabase Cloud to display active emergency campaigns, patient stories, and verified hospital budgets.
- **Instant Mobile Giving:** Native support for MCB Juice QR code payloads, MauCAS instant QR, Blink, my.t money, and bank transfer routing.
- **Child Sponsorship:** View children needing long-term pediatric care, track funding goals, and subscribe to monthly care sponsorship.
- **Audited Financial Statements:** Transparent access to audited financial reports and official NGO regulatory disclosures.
- **Bilingual Experience:** Seamless switching between Français and English.
- **Offline Reliability:** Cached fallback state ensuring campaign data and emergency contact options remain accessible offline.

---

## ⚡ Getting Started

### Prerequisites
- Node.js 20+
- npm 10+
- Expo Go app on iOS or Android (or an Android/iOS emulator)

### Installation
```bash
# 1. Install dependencies
npm install

# 2. Start Expo development server
npx expo start
```

Press `a` to run on Android emulator, `i` for iOS simulator, or scan the terminal QR code with **Expo Go**.
